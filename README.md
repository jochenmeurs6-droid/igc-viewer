# IGC Flugviewer

Zeigt den Flugweg einer IGC-Datei (Segelflug-Logger) auf der Karte und das Barogramm –
direkt im Browser, am PC und auf dem Handy. Die IGC-Datei wird nur lokal im Browser
ausgewertet und nicht hochgeladen.

**Funktionen:** Flugweg eingefärbt nach Höhe, Steigen/Sinken oder Geschwindigkeit ·
Barogramm (Baro- und GPS-Höhe, ENL) · Erkennung von Motorläufen · Anzeige der deklarierten Aufgabe ·
Statistik · Wiedergabe · Maus- und Touch-Bedienung.

Karten: Google Maps (Gelände, Karte, Satellit, Hybrid), OpenStreetMap, OpenTopoMap.
